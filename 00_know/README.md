## 维护规则（改文档前先读）

1. **数字必须有出处**：要么是工具实测（写明命令），要么是源码/资产路径。禁止"大概是"。
2. **状态要标注**：新增/改动的文档必须在**本索引**里写明状态；发现过期就地把状态改成"待更新"并写清哪一段过期。
3. **一件事一个家**：参数真值只在 `30_参数标准/机器人参数单一真值表.md`；任务只在 `任务清单.md`；决策只进 `待你确定.md`。
4. **对账措辞不要改**：本文件里的「更多参考项目（N 个）」被 `tools/doc_reality_check.py` 当锚点校验，改数字必须同步改实测值。
5. **作废不删史**：文档作废移到 `90_归档/` 并在索引里说明原因（`git` 仍留有全文）。
