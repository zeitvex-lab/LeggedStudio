## 维护约定

1. 新增文档按上表分组归位；**代码里已有结论的不要再写一份文档**（文档负责"为什么"，代码负责"是什么"）。
2. 涉及路径的表述用 `00_resources/<project>/<rel>`（与 `00_open/<project>/<rel>` 逐级对应），
   被省略文件按 `_OMITTED.md` 登记的源路径回 `00_open/` 取用。
3. 报告类文档（B 组等）**只追加、不改写历史结论**；结论被推翻时新开一节说明，保留裁决链。
