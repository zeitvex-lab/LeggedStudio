## 一处"没动"的边界

**代码与门禁对文档路径有硬依赖**，移动文档时已同步（否则 `npm run check:docs` 会红）：

| 依赖方 | 内容 |
|---|---|
| `tools/doc_reality_check.py` | **8 个锚点**指向 `05_任务清单.md`（§0 现状锚点），1 个指向本文件（见下条维护规则 2），1 个指向 `01_项目定位.md`（产品版本） |
| `registry/motion_commands.json` | `evidence` 字段的路径 |
| `registry/rewards/conflicts.json`、`registry/packs/imitation_amp.json`、`backend/motion_registry.py`、`tools/audit_motions.py` | 注释与 `evidence` 里的**文档名 + 章节名**（改名时已同步到 `01_项目定位` / `02_项目规划` §核心功能地图） |
| `tools/audit_tools_inventory.py` | 消费面白名单（列出 `00_know` 各文档路径，用于判断工具是否为孤儿） |
| `backend/test_asset_inspection.py`、`contracts/tests/test_physics_{binding,payload_view}.py` | 注释里的文档引用（已改指新路径与 `90_归档/`） |
| `tools/sync_resources.py` | 生成 `00_resources/README.md` 时的链接 |

## 维护规则（改文档前先读）

1. **数字必须有出处**：要么是工具实测（写明命令），要么是源码/资产路径。禁止"大概是"。
2. **对账措辞不要改**：本文件里的「更多参考项目（83 个）」被 `tools/doc_reality_check.py` 当锚点校验，改数字必须同步改实测值。
3. **一件事一个家**：参数真值只在 [`04_参数真值标准.md`](./04_参数真值标准.md)；任务只在 [`05_任务清单.md`](./05_任务清单.md)；上游依据只在 [`03_参考项目与资源.md`](./03_参考项目与资源.md)；**落地方案与阶段计划只在 [`02_项目规划.md`](./02_项目规划.md)**；决策只进 `05` 的待决事项。

4. **已完成的不堆细节**：已完成任务压成一行；**"此路不通"的结论必须留**（它比"做了什么"更省时间）。
5. **作废不删史**：文档作废移到 `90_归档/` 并在归档索引里说明原因（`git log --follow` 仍可追全文）。
