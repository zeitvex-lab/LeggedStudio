## 总验收门（DoD）

1. **零命令行**（桌面形态）：双击 → 配置环境 → 启动 → 导入机器人 → 冒烟 → 训练 → 导出 → 基础仿真，全程在程序内完成。
2. **可扩展不改代码**：新机器人 = 1 目录 + 3 JSON + 模型文件；`onboard → verify → train → export` 全绿且不改 Python（I3）。
3. **可复现**：Bundle 在无本仓库的干净机器上可 R1（回放）与 R2（复算评测）；R3 输出 `environment-lock` 与缺口清单（B12/I4）。
4. **可追溯**：任一策略可回溯 `contract_hash + normalizer_hash + recipe 版本 + seed + 评测报告`（B9/B10）。
5. **物理真值唯一**：PD/armature/频率只在内核一处；导出侧 DENYLIST gate 阻断不一致（B3 + 部署 gate）。
6. **瘦身达标（修订）**：`assets/robots` 639.7 MB → **422.1 MB（v0.36.0 实测）**；`.pyc` = 0。原 ≤300 MB 目标依赖"跨包共享资产根"，因**包自包含原则（用户裁决）**不再可行；剩余进一步缩减需"资产减面"专项（go2w 的 d435i_8.obj 31.7 MB / d435i_4.obj 11.7 MB 等上游高模），或经确认后修订目标值。
