# AimRT Health Monitor

AimRT Health Monitor provides abilities to monitor health status of robots, including cpu, gpu, memory, disk, battery, etc.

## Monitors

* battery: battery state
* cpu: CPU usage, temperature
* disk_stats: disk temperature
* disk: disk usage, read/write speed
* emergency_stop: emergency stop status
* gpu_stats: GPU usage, temperature
* heartbeat: node heartbeat
* mainboard_temp: mainboard temperature
* memory: memory usage
* network: network state
* process: CPU, memory usage of third-party processes
* system_status: overall system status monitor
