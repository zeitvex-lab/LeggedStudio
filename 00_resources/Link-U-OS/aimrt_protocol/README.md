# aimrt_protocol

## Core Responsibilities
  - Defines the communication protocols for Link-U OS, including Protobuf and ROS2 messages (msg), services (srv), and remote procedure calls (RPC). The project also provides the corresponding build chain configurations for integrating and using these protocols in other projects.
