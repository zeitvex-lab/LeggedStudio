## 主体设计

aimrt_process_manager 采用`AIMRT`的整体框架来加载配置和初始化需要的插件, 如果你熟悉`AIMRT`你会发现当前仓库在 main.cc 中借鉴了`AIMRT`的
一部分初始化代码，在框架之上，实现的功能有:
- 基于框架中的Http服务端
- 进程管理
- 进程启动
- 多进程日志落盘
- 进程状态持久化保存

## 启动进程

在创建一个进程时，采用了fork两次的方案，做到了和当前进程的完全隔离。第一次fork, 创建了一个中间进程，主要用于和主进程通讯，第二次fork, 才会开始设置
环境变量，以及IO，gid, uid, session_id等属性，并最终进行 exec操作。

## 停止进程

停止一个在运行的进程时，采用两个步骤:
- 首先是 kill -15 -pid  发送一个负的pid, 表示向session内所有的进程发送15信号
- 如果子进程在超时时间内没有完全退出, 则会将整个进程组中, 每一个进程发送一个-9的信号
