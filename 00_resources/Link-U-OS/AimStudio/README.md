# README

AimStudio 是 agibot 远征系列机器人的远程运维 GUI 工具，为目标用户提供友好的可视化操作界面，让机器人远程运维和管理变得简单直观。

## 目标用户

- 工厂运维人员
- 现场技术人员
- 测试工程师
- 新手用户
  
## 使用场景

### 工厂日常运维

- 可视化连接和管理多台机器人
- 批量部署软件包和更新固件
- 查看机器人健康状态和告警信息
- 导出运行日志和故障诊断数据
  
### 现场故障排查

- 快速查看机器人进程状态和心跳
- 实时监控磁盘空间和系统资源
- 一键启动/停止应用模块
- 导出系统日志和网络抓包进行分析

### 工厂产线测试

- 执行综合健康检查流程
- 部署工厂参数和配置文件
- 备份和恢复机器人资源
- 查看 EM 应用状态和日志
  
### 数据管理与归档

- 导出机器人运行日志（ROS bag、系统日志）
- 批量导出多芯片数据
- 网络流量抓包和分析
- 历史数据备份与恢复
