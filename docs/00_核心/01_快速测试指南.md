## ⚡ 快速测试（2 步）

### Step 1：测试后端（1 分钟）

```powershell
cd C:\Users\31560\Documents\00_open\legged_studio\backend
pip install -r requirements.txt
python server.py
```

**预期输出**：
```
INFO: Started server process
INFO: Uvicorn running on http://127.0.0.1:8765
```

**验证**：浏览器访问 http://127.0.0.1:8765/health

应该看到：
```json
{
  "status": "ok",
  "version": "0.1.0",
  "python_version": "3.12.2"
}
```

按 `Ctrl+C` 停止服务器。

## 🐛 常见问题

### Q: `ModuleNotFoundError: No module named 'fastapi'`

```bash
pip install fastapi uvicorn
```

### Q: 端口 8765 被占用

```powershell
netstat -ano | findstr 8765
taskkill /PID <进程ID> /F
```

### Q: Electron 窗口空白

检查后端是否启动（查看控制台日志）
