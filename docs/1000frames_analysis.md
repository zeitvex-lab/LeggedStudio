## 📊 核心设计模式

### 1. API 清单驱动
- `API_MANIFEST.json` — 定义所有算法和 API
- 结构化的算法配置
- 版本化管理

## 🎨 UI/UX 模式

### 快速体验流程
1. **选择预训练模型** → 2. **一键试玩** → 3. **查看结果**

### 训练流程
1. **配置任务** → 2. **选择算法** → 3. **开始训练** → 4. **监控进度** → 5. **评估结果** → 6. **导出 ONNX**

### 界面布局
```
┌─────────────────────────────────────┐
│ Header (Logo + Status)              │
├─────────────────────────────────────┤
│ Quick Actions                       │
│ [Quick Demo] [New Training] [Models]│
├─────────────────────────────────────┤
│ Training Tasks (Cards)              │
│ ┌──────┐ ┌──────┐ ┌──────┐        │
│ │Task 1│ │Task 2│ │Task 3│        │
│ └──────┘ └──────┘ └──────┘        │
└─────────────────────────────────────┘
```
